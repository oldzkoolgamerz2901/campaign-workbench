---
name: research
description: Investigate an authorized research question using high-trust primary sources and present cited findings; save to repository only when authorized.
---

Research only the question and deliverable authorized by the owner. Delegate to a background agent when available and authorized; otherwise perform the investigation directly. Delegation does not grant additional scope or execution permissions.

Research procedure:

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Present a concise research report with primary-source citations, uncertainties, disagreements, and limitations. Distinguish evidence from recommendations.
3. Write a Markdown file only if repository persistence is authorized. Use existing documentation conventions; otherwise provide the report in the conversation for review. Research does not authorize design, planning, implementation, or automatic advancement.
