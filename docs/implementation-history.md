#### UW2 — implementation and developer evidence — 2026-10-23

The owner approved the documented UW2 boundary after the planning handover. Implemented Preparation-owned `SessionLibraryService` and its three HTTP operations: `GET`/`POST /api/campaigns/{campaign}/sessions/{id}/library` and `PUT .../library/{item}`. Catalogue filtering remains Writing-owned; Preparation overlays session revision, origin-qualified whole-card matches, update availability and same-type update eligibility. No persistence-owning Library, reverse Preparation→Playthrough dependency or new frontend feature was introduced.

New Add validates capture, conflicts, session revision and the exact catalogue Draft ID/revision pair; Source-only Add reuses Writing's associated-edit operation before exact approval and independent Preparation content/artwork freezing. All writes share the transaction. Failure rolls back Draft, association, retained approval, artwork and session changes. An existing whole-card match returns every matching ID in preparation order without updating it or advancing the session revision; that safe retry path deliberately tolerates stale session/Draft expectations, including the original Source→Draft transition, while still rejecting a stale capture or identity conflict. Historical multiple matches remain explicit choices. Section captures never satisfy whole-card membership; an imported item's original campaign identity must match the current campaign to satisfy membership or qualify for replacement.

Explicit replacement validates the selected item and saved representation, requires the same logical origin identity/type, and reuses the existing approval/freezing implementation. It preserves item ID, order, item/session notes and compatible runtime state, replacing frozen content/artwork/provenance/outgoing bindings atomically. An already-current replacement is a no-op after expectation validation. Other documents' old exact incoming links become unavailable when the old target revision is absent. Legacy full Source snapshots with valid frozen identity/type can be replaced explicitly; section and foreign-origin copies cannot be rebound.

Existing provenance, classification and section fields completely represent UW2; no migration, persisted field or archive format change was needed. Session JSON/ZIP v7 and Writing JSON v3 / ZIP v4 remain current. Existing Source/Draft frontend pathways remain available until their separately gated UX replacement.
